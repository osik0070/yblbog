## 📊 경쟁사 심층 분석 데이터 수집 계획

Writer의 초안(실행 중심 로드맵)을 바탕으로, 독자 반응 예측과 콘텐츠 방향 설정을 위한 경쟁사 분석을 위해 다음의 데이터 수집 항목을 정의하고 실행 계획을 수립합니다.

### 1. 경쟁사 선정 기준 정의

분석 대상 경쟁사는 '애드센스 자격 획득' 또는 '자가학습을 통한 수익화'라는 핵심 주제를 다루는 블로그/콘텐츠를 제작하며, **실질적인 트래픽 및 수익화 성과**를 입증하는 채널로 한정합니다.

*   **선정 기준:**
    1.  **주제 일치성:** 애드센스, 온라인 수익화, 디지털 자격증, 자기계발 관련 콘텐츠를 주력으로 다루는 채널.
    2.  **실행 중심성:** 단순 이론 나열이 아닌, 구체적인 방법론, 툴 사용법, 실제 경험을 공유하는 콘텐츠를 제작하는 채널.
    3.  **권위 확보:** 해당 분야에서 어느 정도의 전문성과 독자 신뢰도를 확보하고 있는지 분석.

### 2. 핵심 분석 데이터 항목 (Metrics)

선정된 경쟁사들에 대해 다음의 데이터를 수집하여 정량적/정성적 분석을 수행합니다.

| 분석 항목 | 세부 내용 | 목표 |
| :--- | :--- | :--- |
| **콘텐츠 트렌드** | 경쟁사들이 현재 가장 높은 트래픽을 유도하는 주제 및 키워드. | 최신 트렌드 반영 및 콘텐츠 주제의 적합성 확인 |
| **후크(Hook) 분석** | 경쟁사 콘텐츠의 도입부(제목, 첫 문단)에서 독자의 클릭을 유도하는 심리적 장치 분석. | Writer가 제안한 후크의 효과 검증 |
| **수익화 지표** | 블로그/콘텐츠를 통해 추정 가능한 광고 수익 수준, 제휴 마케팅 성공 사례 등. | 콘텐츠의 잠재적 수익화 가능성 평가 |
| **구조 및 흐름** | 콘텐츠의 목차 구성, 정보의 깊이, 실행 단계의 구체성 분석. | Writer의 5단계 워크플로우의 구조적 우위 확인 |
| **독자 반응** | 댓글, 공유 수 등을 통해 독자들이 콘텐츠에 대해 실제로 얻은 가치(Pain Point 해결 정도) 분석. | 독자가 원하는 정보와 실제 제공되는 정보의 간극 파악 |

### 3. 데이터 수집 실행 계획 (Action Plan)

**Phase 1: 경쟁사 리스트 확보**
*   **Action:** 애드센스/수익화 관련 상위 5개 블로그/유튜브 채널 리스트를 1차로 확보합니다. (다음 단계에서 구체적인 채널명 입력 필요)

**Phase 2: 심층 데이터 수집**
*   **Action:** 확보된 경쟁사 리스트를 기반으로, 각 채널에서 **최근 3개월 이내의 상위 10개 포스팅/영상**을 선정하여 분석을 시작합니다.
*   **Action:** 각 콘텐츠에 대해 위에서 정의한 **핵심 분석 데이터 항목**을 수집하고 표 형식으로 정리합니다.

**Phase 3: 트렌드 및 갭 분석**
*   **Action:** 수집된 데이터를 바탕으로, 경쟁사들이 다루지 않거나 약하게 다루는 **'실행 중심' 영역**을 식별하여, 우리 콘텐츠의 차별화 포인트(Unique Selling Proposition)를 도출합니다.
